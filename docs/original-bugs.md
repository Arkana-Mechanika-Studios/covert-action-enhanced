# Original bugs and quirks register

Suspected bugs and quirks of the shipped game, found while reading the matched C. Each
entry stays here until it is confirmed (by a run of the original, or a trace) or ruled
out. The matched C reproduces all of them exactly; nothing here has been changed.

Handling once confirmed, as agreed for the Darklands restoration:
- **Data-damaging** (corrupts a save or the campaign): reproduced exactly behind a switch,
  fixed by default.
- **Plain visual glitch**: fixed in every player mode and documented; exact only for the
  oracle.
- **Other quirks** (gameplay behaviour a player could rely on): reproduced exactly,
  documented.

Since 16 Nov 2026 (the launcher's Advanced tab, csharp/docs/faithfulness/DIVERGENCES.md D-650) a bug not fixed
for every player (CA-1, 5, 17, 26, 27, fixed in 1.0) is fixed only when the player asks: **Fix the original's bugs**
(`fixes.originalBugs`) for the safe group, **Also fix campaign-logic bugs** (`fixes.campaignBugs`) for those that change
the story. Both are off by default: the game then plays as 1.0 and the original.
